# Gestion des notes d'étudiants (C)

Application console en langage C pour gérer les notes d'étudiants.

## Fonctionnalités
- Ajouter un étudiant (nom et 3 notes)
- Afficher la liste
- Calculer la moyenne
- Classer par moyenne
- Rechercher un étudiant par nom
- Sauvegarder et charger les données dans un fichier

## Compilation et utilisation
gcc main.c -o notes
./notes

## Notions utilisées
Structures, tableaux, fonctions, tri, fichiers
